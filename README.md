# DuetRNA

Official codebase for **Base-and-Sugar Dual-Frame Flow Matching for RNA
Co-Design**.

The complete code release is in [`DuetRNA/`](DuetRNA/): data preprocessing,
training, checkpoint resume, generation, and evaluation. See the
[installation and usage guide](DuetRNA/README.md).

```bash
git clone https://github.com/XjunLi/DuetRNA.git
cd DuetRNA/DuetRNA
```

Run the installation and usage commands from this inner `DuetRNA/` directory.
Datasets, model weights, generated outputs, and development logs are not
included in the code release.
