# DuetRNA
Official codebase for DuetRNA. Code coming soon.

## Project website

The website, media, viewers and site-maintenance scripts are contained in [`docs/`](docs/).
GitHub Pages publishes **`main` → `/docs`** at [xjunli.github.io/DuetRNA](https://xjunli.github.io/DuetRNA/).
The repository root is reserved for the forthcoming model code.

Preview from the repository root:

```sh
python -m http.server 8000 --directory docs
```

See [`docs/SITE.md`](docs/SITE.md) for editing and validation, and
[`docs/SITE_COMMIT_POLICY.md`](docs/SITE_COMMIT_POLICY.md) for maintenance rules.

Work directly on `main`. Do not create additional branches or pull requests unless the owner explicitly changes this instruction.
