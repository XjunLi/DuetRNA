# gRNAde benchmark checkpoint

The bundled adapter expects the benchmark-compatible gRNAde v0.3 checkpoint:

```text
external_tools/grnade_api/checkpoints/gRNAde_ARv1_1state_all.h5
```

Obtain it from the upstream
[gRNAde v0.3.2 checkpoint directory](https://github.com/chaitjo/geometric-rna-design/tree/v0.3.2/checkpoints).
Weights are intentionally ignored by Git. Record the exact source and version
used for every formal IF evaluation.
